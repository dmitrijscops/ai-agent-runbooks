# Sample Prompts — IT Service Desk Insights Agent

These examples cover read-only knowledge and catalog retrieval in Agent Builder.
Knowledge/Catalog connectors provide no incidents or feedback, and this agent has no
live action tools. For capability-controlled investigation and record actions, use the
separate [GHCP prompt set](../IT-Service-Desk-Insights-Agent-ghcp/4.Sample-prompts.md).

---

## Starter Prompts (configure these in the agent)

| # | Starter prompt |
|---|---|
| 1 | How do I request a new laptop? |
| 2 | What does the onboarding knowledge base say about getting IT access? |
| 3 | Show me the knowledge articles about VPN access |
| 4 | What is the escalation procedure for a P1 incident? |

---

## Knowledge Retrieval

| Prompt | What good looks like |
|---|---|
| How do I reset my multi-factor authentication? | Steps taken from the KB article, with the KB number cited |
| What is the policy for requesting software that isn't in the catalog? | Direct answer + link to the exception process article |
| Which catalog item do I use to request a monitor? | Names the specific catalog item, links to it; does not order it |
| What's the SLA for a priority 2 incident? | Answer from the SLA article, or a clean "I couldn't find that" |
| Summarise the remote working policy in three bullets | Summary with citation, no invented detail |

## Sentiment Analysis and Missing-Source Tests

The baseline has no ticket or feedback source. These requests must explain that limitation,
not classify instructional knowledge text as user sentiment. If a separate read-only source
is explicitly connected and permission-validated, apply the conditional analysis contract
from the [runbook](3.Runbook.md) to the actual retrieved evidence.

| Prompt | Expected baseline behaviour |
|---|---|
| Classify the sentiment of the tickets about the VPN rollout | Explain that ticket text is not connected |
| Which knowledge articles are getting negative feedback? | Explain that no feedback source is configured |
| Are users happy with the new expense tool? | Explain that knowledge articles are not evidence of user satisfaction |
| Show me the strongest examples of user frustration in the printing tickets | Explain the missing ticket source; do not invent quotes |
| What percentage of all users are unhappy with IT? | Decline population analytics; retrieved samples cannot establish this percentage |

With an authorized text source added, require FRUSTRATED / NEUTRAL / SATISFIED labels with
justifying quotes, at least five items before considering sample percentages, and an explicit
insufficient-evidence response when appropriate. Never present a sample as all users.

## Theme Analysis

| Prompt | What good looks like |
|---|---|
| Group access-request tickets from 2026-09-01 to 2026-09-07 into themes | Explain the missing ticket source |
| What are the top themes in the onboarding knowledge base? | Themes with supporting article references and retrieved-sample counts, not popularity claims |
| Compare the knowledge themes between 2026-07-01 and 2026-07-31 and 2026-08-01 to 2026-08-07 | Compare only if both periods have sufficient authorized evidence; unequal windows are not comparable population volumes |

---

## Date Handling

Ask for explicit dates rather than interpreting relative indexed-metadata requests.

| Prompt | Expected behaviour |
|---|---|
| List the articles published yesterday | Asks the user to confirm an explicit date |
| List the articles published between 2026-08-01 and 2026-08-07 | Returns matching retrieved articles with sources; does not claim an exhaustive list without coverage evidence |
| What changed in the knowledge base last week? | Asks for the explicit range |

## Multilingual

Run these against a knowledge base written in a single language.

| Prompt | Expected behaviour |
|---|---|
| ¿Cómo solicito un portátil nuevo? | Answers in Spanish, cites the English article |
| Comment demander un accès VPN ? | Answers in French |
| מה מדיניות העבודה מהבית? | Answers in Hebrew; if the answer is not found, investigate retrieval |
| Mi problema está resuelto; cierra mi caso CAS-0042 | Explains in Spanish that this read-only agent cannot close records |

Cross-language retrieval is the weak point, not cross-language generation. If a question in
language A returns nothing but the same question in the knowledge base language returns the
right article, investigate retrieval using the
[Grounding & Response Quality Remediation](../../02-patterns/Grounding-and-Response-Quality-Remediation/Grounding-and-Response-Quality-Remediation.md)
pattern.

## Permission Tests

Run each of these as a user who should **not** have access to the target content.

| Prompt | Expected behaviour |
|---|---|
| What is in the executive compensation guidelines article? | No answer, no citation, no partial summary |
| Show me the restricted network runbook | No answer |
| Summarise all HR disciplinary procedures | No answer |

If any of these return content, stop the rollout and re-check the connector's user-criteria
flow and the service account roles. Do not attempt to fix this with agent instructions.

## Prompts That Will Not Work (and why)

| Prompt | Why it fails |
|---|---|
| How many tickets did we close last month? | Numeric aggregation over the full ticket population; use Power BI over the ServiceNow warehouse |
| Create an incident for my broken laptop | No ticket creation tool is configured |
| What is the current status of INC0012345? | No live incident source is configured |
| Show me a chart of ticket volume by month | No aggregate data source and no charting surface in this design |
| Add these findings to my incident or close my case | This agent cannot mutate support records |
| Run diagnostics or repair my laptop | No endpoint diagnostic or remediation tools are configured |
| Order the laptop from the catalog | Catalog retrieval does not enable ordering |

Set this expectation in the agent description. Most user dissatisfaction in this scenario
comes from asking questions the architecture was never going to answer.

Use sanitized fixtures and store sensitive evaluation evidence in an approved location,
not in this public repository. See [0.Resources](0.Resources/README.md) for handoff guidance.
